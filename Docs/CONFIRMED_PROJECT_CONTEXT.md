# CONFIRMED_PROJECT_CONTEXT

寫在這裡的東西是紅線。改這份文件需要使用者明確同意。

## 這個專案是什麼
- 本機表情訊號日記原型,代號 FaceTrace。
- 體驗流程:開鏡頭看到 face mesh → 對鏡頭講 60 秒 → 即時曲線捲動 → 結束跳出日記頁(完整軌跡 + 自動標出變化點) → 展示者蓋上筆電說明資料哪都沒去。
- 2026-08-23 14:00 桃園,向聊心茶室(HealYou)創辦人與工程師展示。展示的是設計判斷,不是工程量。

## 這個專案不是什麼
- 不是情緒辨識。不輸出情緒標籤,這是科學立場(表情到情緒的推論不成立)與法規立場(歐盟 AI Act 方向)的雙重決定。
- 不是產品。是原型,開場就會自己講明。
- 不是聊心茶室的委託。是自主作品,同時是 MUM 2026 demo 的前身。

## 三個設計決定(展示時要講的,程式必須體現)
1. 軌跡不貼標籤:只標「第 N 秒有明顯變化」,不說那是什麼情緒。
2. 全本機:執行期零網路,資料不出裝置。
3. 不確定性可見:信心低就變灰,誠實是功能。

各決策的完整依據見 Docs/references/DESIGN_EVIDENCE.md
